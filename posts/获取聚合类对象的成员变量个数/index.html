获取聚合类对象的成员变量个数

C++ 没有提供对应的反射获取类的相关参数，这里使用元编程的方法尝试获得

发表于 2024/12/12
作者 墨墨鱼
5 分钟阅读

聚合类型

对于聚合类型，在 C++17 及以上标准中有对应的标准实现，即使用 is_aggregate_v<T>() 确认。简要来说，就是我们的类不能有自定义构造函数，或者继承自这样的类，同时成员变量不能私有或者被保护。

#include <unistd.h>

#include <iostream>
#include <string>
#include <type_traits>

struct A {
    std::string a;
};

struct B {
    int a;
    double b;
    std::string c;
};

struct C {};

void test_func() {
    std::cout << member_count<A>(); // 1
    std::cout << member_count<B>(); // 3
    std::cout << member_count<C>(); // 0
}

auto main() -> int {
    test_func();
    return 0;
}

// C++ 20 中

struct AnyArg {
    template <typename T>
    operator T();
};

template <typename T>
    requires std::is_aggregate_v<T>
constexpr auto member_count(auto&&... args) -> size_t {
    // 递归测试 类型 T, 测试从0个到第一次出现构建会失败的参数量
    // 实际上实例化了 `n + 2` 个 `member_count()` 函数
    if constexpr (not requires { T{args...}; }) {
        return sizeof...(args) - 1;
    } else {
        return member_count<T>(AnyArg{}, args...);
    }
}

C++17

在 C++17 中少了 requires 表达式支持，所以 if constexpr 缺少直接使用参数构建测试是否成功的方法。

当然也尝试使用 std::is_constructible 来测试是否能够构建，但是该语法除了通过参数构建类型的功能以外，还可以通过参数隐式转换为目标类，这样就会导致空类出现错误结果:

1

struct AnyArg {
    template <typename T>
    operator T();
}

std::discard = std::is_constructible_v<T, AnyArg>; // 返回总是 `true`

这样不能正确推理出成员变量的数量。所以采用老版本的方法：采用 tag 类，通过链式继承： tag<n> -> tag<n - 1> -> ... -> tag<0>.

这样就可以通过重载函数匹配参数，从多个参数到 0 个参数逐个测试，以达到返回对应聚合类型成员变量数量的目的。

C++ 17

struct AnyArg {
    template <typename T>
    operator T();
};

template <unsigned I>
struct tag;

template <>
struct tag<0> {};

template <unsigned I>
struct tag : tag<I - 1> {};

template <typename T>
constexpr auto member_count_impl(tag<4>)
    -> decltype(T{AnyArg{}, AnyArg{}, AnyArg{}, AnyArg{}}, 0u) {
    return 4u;
}

template <typename T>
constexpr auto member_count_impl(tag<3>)
    -> decltype(T{AnyArg{}, AnyArg{}, AnyArg{}}, 0u) {
    return 3u;
}

template <typename T>
constexpr auto member_count_impl(tag<2>)
    -> decltype(T{AnyArg{}, AnyArg{}}, 0u) {
    return 2u;
}

template <typename T>
constexpr auto member_count_impl(tag<1>) 
    -> decltype(T{AnyArg{}}, 0u) {
    return 1u;
}

template <typename T>
constexpr auto member_count_impl(tag<0>) 
    -> decltype(T{}, 0u) {
    return 0u;
}

template <typename T, typename = std::enable_if_t<std::is_aggregate_v<T>>>
constexpr auto member_count() -> size_t {
    return member_count_impl<T>(tag<4>());
}

template <typename T, typename = std::enable_if_t<std::is_aggregate_v<T>>>
constexpr auto member_count() -> size_t {
    return member_count_impl<T>(tag<4>());
}

上述内容要求我们付出一些 体力劳动 或者使用宏批量展开来扩展 member_count_impl.
